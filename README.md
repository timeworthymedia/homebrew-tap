# Time Worthy Media Homebrew Tap (`homebrew-tap`)

Official Homebrew Tap for Time Worthy Media open-source tools and utilities.

## Installation & Usage

To install **Vostego LanguageTool Manager & Launcher**:

```bash
# 1. Tap the repository
brew tap timeworthymedia/tap

# 2. Install vostego-languagetool
brew install timeworthymedia/tap/vostego-languagetool

# 3. Launch & auto-configure background server & web extensions
vostego-languagetool -configure-apps
```

## Available Formulas

- **`vostego-languagetool`**: Standalone LanguageTool manager, background service supervisor, and app auto-configurator ([github.com/timeworthymedia/vostego-languagetool](https://github.com/timeworthymedia/vostego-languagetool)).
